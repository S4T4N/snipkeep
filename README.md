# 🧠 SnipKeep

> بنك المقتطفات الذكي - ابحث بالمعنى، نفذ بأمان.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)

## 💡 ما المشكلة التي تحلها؟

كل مطور يجمع مقتطفات برمجية. لكن:
- تنسى أين حفظتها
- تبحث في ملفات notes قديمة
- تعيد كتابة نفس الكود مراراً

**SnipKeep** يحل هذا بالذكاء الاصطناعي. ابحث بالمعنى، وليس بالنص.

## ✨ الميزات

- 🔍 **بحث دلالي**: ابحث عن "كيف أرتب قائمة" وستجد كود `sorted(list, key=...)`
- 🏷️ **تصنيف تلقائي**: يكشف اللغة والوسوم تلقائياً
- 🛡️ **تشغيل آمن**: نفذ المقتطفات في بيئة معزولة
- 🎨 **واجهة جميلة**: تمييز للأكواد وألوان في الطرفية
- 💾 **قاعدة محلية**: بياناتك على جهازك فقط

## 📦 التثبيت

```bash
# استنساخ المستودع
git clone https://github.com/username/snipkeep.git
cd snipkeep

# تثبيت التبعيات
pip install -r requirements.txt

# أو تثبيت مباشر (عند الرفع على PyPI)
pip install snipkeep

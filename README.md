## 💡 لماذا SnipKeep؟

كل مطور لديه مئات المقتطفات البرمجية، لكن المشكلة:

* 🔍 تضيع بين الملفات والملاحظات القديمة
* 🧠 تنسى اسم الدالة أو الكود الذي كتبته سابقًا
* 🔁 تعيد كتابة نفس الحلول مرارًا

**SnipKeep** يجعل إدارة الكود أسهل عن طريق البحث الذكي باستخدام المعنى، وليس مجرد تطابق النص.

## ✨ المميزات

### 🔍 بحث دلالي ذكي

ابحث بطريقة طبيعية:

> "كيف أرتب قائمة في بايثون؟"

وسيجد لك:

```python
sorted(items, key=lambda x: x.value)
```
